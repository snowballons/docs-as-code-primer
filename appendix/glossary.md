# Glossary

| Term | Definition |
|------|------------|
| **Docs as Code** | Authoring, reviewing, testing, and releasing documentation with software engineering tooling and discipline |
| **Primer** | Opinionated teaching layer in this repository (`primer/`) |
| **Scaffold / kit** | Copy-paste folder structure and starter automation (`scaffold/`) |
| **Internal documentation** | Deep, honest docs for builders and operators |
| **User-facing documentation** | Curated, goal-oriented docs for product consumers |
| **Shared content** | Single-source artifacts referenced by both streams |
| **ADR** | Architecture Decision Record |
| **DocOps** | CI/CD, review, and publishing operations for documentation |
| **SSoT** | Single source of truth |
| **Diagrams as code** | Diagrams authored as text (e.g. Mermaid) and rendered to images/SVG |
| **Agent-ready docs** | Structured, stable, machine-friendly documentation entry points for AI coding agents |
