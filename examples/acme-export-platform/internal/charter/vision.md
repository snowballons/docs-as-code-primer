# Vision — Acme Export Platform

## Vision statement

This project builds a self-service data export platform that allows enterprise customers to download their account data in multiple formats without engineering intervention. It reduces support ticket volume, improves compliance posture, and gives customers autonomy over their data.

## KPIs

| Objective | Metric | Baseline | Target | Timeframe |
|-----------|--------|----------|--------|-----------|
| Reduce export-related support load | Tickets / month | 120 | ≤ 48 (−60%) | 3 months post-launch |
| Adoption | % enterprise customers using self-service export | 0% | 80% | 6 months |
| Performance | Job completion time for ≤ 1M rows | n/a | < 30s | At launch |

## Scope (summary)

**In:** CSV/JSON/XLSX export for account usage data; email when ready; API for automation.

**Out (v1):** Real-time streaming export; non-enterprise tiers; custom SQL exports.
