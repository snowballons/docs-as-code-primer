# Glossary — Acme Export Platform

| Term | Definition |
|------|------------|
| Export job | An asynchronous request to produce a downloadable data file |
| Entitlement | Billing-verified right to use export features |
| Worker | Internal process that executes export jobs from the queue (internal term; avoid in user docs unless needed) |
| Download URL | Time-limited URL returned when a job completes |

User and internal docs should link here instead of redefining these terms.
